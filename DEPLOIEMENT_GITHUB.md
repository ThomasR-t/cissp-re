# Publier CISSP Coach gratuitement avec GitHub Pages

1. Connectez-vous à https://github.com/new et créez un dépôt **public** nommé `cissp-coach` (ne cochez pas de licence ni de README initial).
2. Dans ce dépôt, sélectionnez **Add file → Upload files**. Déposez **les fichiers contenus dans ce dossier** à la racine du dépôt (et non le ZIP ou un dossier parent), puis cliquez sur **Commit changes**.
3. Ouvrez **Settings → Pages**. Sous **Build and deployment**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)` et **Save**.
4. Après la publication, ouvrez `https://VOTRE-PSEUDO.github.io/cissp-coach/`.
5. Sur mobile, utilisez l'option du navigateur **Ajouter à l'écran d'accueil** pour installer le raccourci.

## Attention à la progression
Les résultats sont enregistrés dans le stockage local du navigateur. Ils **ne sont pas synchronisés automatiquement** entre les appareils, même si le site est accessible partout. Exportez régulièrement votre progression JSON depuis l'application, puis importez-la sur l'autre appareil. L'import/export manuel reste gratuit et ne requiert aucun serveur.

## Sécurité et vie privée
Ce dépôt ne contient pas vos résultats personnels. Un dépôt public rend le code et les questions accessibles à tous. N'y téléversez pas vos exports de progression. La publication GitHub Pages nécessite un dépôt public sur l'offre GitHub gratuite.

## Maintenance
Pour mettre à jour l'application, remplacez les fichiers du dépôt. Le navigateur peut conserver une ancienne version via le service worker ; fermez/réouvrez le site ou videz les données du site si nécessaire (attention, cela efface la progression locale : exportez-la avant).
